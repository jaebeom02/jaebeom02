# 김재범 | Backend & Data

Python과 Java를 활용해 데이터를 서비스로 연결하는 백엔드를 개발해 왔습니다.  
주가예측·경제 뉴스 서비스, 음성 기반 서비스, IoT 프로젝트를 경험했습니다.

## 프로젝트

### 주가예측 경제 플랫폼

주가예측 결과와 경제 정보를 제공하는 서비스입니다.

- **담당 영역:** FastAPI·MySQL 기반 백엔드 개발
- **구현 경험:** 추천·리포트·예측 관련 기능을 API와 데이터 저장·조회 기능으로 연결
- **관련 기술:** Python, FastAPI, MySQL, LSTM

### 경제 뉴스 숏폼 플랫폼

경제 뉴스를 요약하고 추천하는 숏폼 서비스입니다.

- **개발 경험:** 경제 뉴스 요약·추천 기능과 서비스 백엔드 구현
- **저장소에서 볼 수 있는 내용:** 뉴스 API 연동, 키워드·선호도 처리, TTS 관련 모듈
- **관련 기술:** Python, FastAPI, TTS, Java

[백엔드 저장소](https://github.com/jaebeom02/backend) · [앱 저장소](https://github.com/jaebeom02/short-economy)

### 음성 기반 면접 피드백·강의 저장

음성을 텍스트로 변환해 면접 피드백과 강의 내용 저장에 활용한 개발 경험입니다.

- **개발 경험:** STT 기반 음성의 텍스트 변환, 면접 피드백 및 결과 저장 기능
- **활용 목적:** 음성으로 남은 내용을 다시 확인할 수 있는 정보로 제공
- **관련 기술:** STT, 웹 백엔드

### 생각하는 의자

센서를 활용해 사용자의 학습 상태를 확인하는 IoT 프로젝트입니다.

- **담당 경험:** Python으로 센서 입력값을 확인하고 반복 측정을 통해 상태 판단 기준 설정
- **관련 기술:** Python, IoT 센서
